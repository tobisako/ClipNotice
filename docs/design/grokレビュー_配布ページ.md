## 2回目レビュー全文

# ClipNotice LP 最終レビュー（辛口）

元データ以外は事実として扱わない前提で、**公開文面そのもの**だけを突き合わせた。測定値・ユーザー数・優越表現の盛りは見当たらない。前回指摘（自虐削除・設定表・3秒デフォルト・デモ範囲）はおおむね反映済み。残るのは「正しさの粒度」と「言い切りの癖」である。

---

## 重要度：高

### 1. `only` ブロック／03「3秒で消える」
**該当:** 「3秒はデフォルト値です。」

**問題:** 事実サマリでは、表示時間スライダー（0.5〜5秒・デフォルト3秒）は **CHANGELOG 0.3.1 の Windows 追加**。macOS 側に「デフォルトの中から選ぶ」根拠がない。ここだけ読むと **両OSで変更可能なデフォルト** に読める。ステータスの格上げに近い。

**直し:**
- 案A: 「表示時間のデフォルトは3秒です（変更は Windows 版の設定）。」
- 案B: 「放っておけば消えます（標準は3秒。クリックで即消去）。」＋詳細は Settings に寄せる。

Settings ブロックでは Win 限定と書けているので、**ここが唯一の食い違いの震源**。

---

### 2. `Usage & Settings`／操作の1行目
**該当:** 「コピー → 左上に付箋表示 → 3秒後に自動消去」

**問題:**
- **3秒** … Win で変更後は不正確。デフォルト動作なら「デフォルト3秒」と書く。
- **左上** … Win はドラッグ位置を引き継ぐので、常に左上ではない。初期／未移動時の話なら「左上（初期位置）」など。

**直し:**  
「コピー → 付箋表示（初期位置は左上）→ 自動消去（デフォルト3秒）」  
操作説明は **初期状態の挙動** に揃える。

---

### 3. `hero`／「付箋で3秒出る。」
**該当:** 見出し相当の2行

**問題:** 高1と同じ。キャッチとして3秒を固定値に見せている。03で修正するなら hero も同じ文法に。

**直し:**  
「付箋で出る。標準は3秒で消える。」  
または「付箋が出て、消える（標準3秒）。」  
「デフォルト」を hero に無理に詰めないなら、**「標準は3秒」** で足りる。

---

## 重要度：中

### 4. `remote`／末尾
**該当:** 「ペーストして確かめる前に、目で分かる。」

**問題:** 直前の「どちらのPC画面に付箋が出たかで…一目で分かります。」の言い直し。事実の追加はない。データなき解釈というより **決めゼリフの二重化**。個人開発小物LPとしては一段くどい。

**直し:** この1文は **削除**。前の文で用は足りている。

---

### 5. `install`／macOS「ログイン時に自動起動」
**該当:** 「`.build/release/clipnotice` を追加（ソースからビルドした場合のパス）。」

**問題:** 嘘ではない。だが Install の推奨は **Homebrew**。推奨経路の自動起動パスが無い。寒いというより **手順が途中で切れている**。

**直し（事実の範囲で）:**
- ソースビルド: 現状のまま。
- Homebrew: 「`which clipnotice` などで得た実行ファイルパスをログイン項目に追加」程度（具体パスを捏造しない）。  
元データに brew のフルパスが無いので、**パスを決め打ちしない**こと。

---

### 6. `colophon`／0.3.1 の要約
**該当:** 0.3.1 の説明文全体

**問題:** 元 CHANGELOG にある **z-order 修正** が落ちている。創作ではないが、奥付を履歴の要約とするなら **数え落とし**。

**直し:**  
「…。z-order 修正。付箋のドラッグ移動・表示時間スライダー・設定パネルの自動クローズを Windows に追加。」  
LPで実装詳細を削る方針なら、**「要約であり CHANGELOG が正」** と奥付に一言あってもよい（現状 Changelog リンクはあるので、z-order を足すか「抜粋」と明示するかのどちらか）。

---

### 7. ナビ表記と見出しの揺れ
**該当:** ナビ「Not a Manager」／見出し「Not a clipboard manager」

**問題:** 同じセクションを指すのに切り方が違う。文法・トーンの一貫性の話。中身の事実誤認ではない。

**直し:** ナビも「Not a Manager」で通すなら見出しも短く揃えるか、ナビを「Not a clipboard manager」に戻す。**どちらか一方の文法に固定。**

---

## 重要度：低（任意・好み）

### 8. `hero`／「Swift + AppKit / C# + WinForms — 保存するものは、何もない。」
**問題:** 技術スタックと「保存しない」をダッシュでつなぐのは、事実はどちらも正しいが **コントラリアン接続** に近い。`diff` で十分言っている。

**直し:**  
「Swift + AppKit / C# + WinForms。」だけにするか、保存しない話は `diff` に一本化。

---

### 9. 「それだけ。」の反復（spread / only / hero 付近 / footer）
**問題:** 虚偽ではない。Retro Zine の声としては成立。ただし **最小性を売り文句として連打**しており、測定値こそ無いがトーンとしては盛り寄り。公開前に1回は削って間を取った方が品が出る。

**直し候補:** spread「コピーした。→ 出た。」の直後の「それだけ。」か、hero の「↑ これが3秒で消える。それだけ。」のどちらか一方を残す。

---

### 10. `demo`／「ClipNotice を入れていれば、ブラウザの外の「本物」も同時に出ます。」
**問題:** 監視は 0.5秒ポーリングなので「同時」は厳密には最大約0.5秒遅れ。揚げ足だが、技術ページなら「本物の付箋も（監視のタイミングで）出ます」の方が誠実。

**直し:** 「入れて常駐していれば、本体側の付箋も出ます。」

---

### 11. Settings がナビに無い
**問題:** `Usage & Settings` は長い実質セクションなのにナビは Demo / Not a Manager / Remote / Spec / Install。迷子ではないが、設定表の出典を推すなら `#settings` への導線があるとよい。必須ではない。

## 削るべき／足すべき（要約）

**削る**
- remote 末尾「ペーストして確かめる前に、目で分かる。」
- （任意）hero のスタックと「保存しない」のダッシュ接続、「それだけ。」の重複1つ

**直す（足すというより限定する）**
- 「3秒＝デフォルト」を **Windows で変更可／全体の標準動作** としてプラットフォーム差が矛盾しない言い方に統一（hero / only 03 / Usage）
- Usage の「左上」「3秒」を初期・デフォルト動作に限定

**足りない（事実の範囲）**
- Homebrew 利用時のログイン項目の足し方（パス捏造なし）
- 0.3.1 の z-order、または奥付が抜粋であることの明示

## 表記・一貫性チェック（短評）

- **です・ます** と **体言止め／「それだけ。」** の混在は Zine としては意図的で、破綻はしていない。
- **macOS / Windows** と **mac / win** の混在は Settings の括弧書き程度なら許容。ナビ英語だけがやや浮く。
- **タグ重複**（HTMLの二重タグ）はこのテキスト抽出だけでは断定不能。中身の事実の二重説明（0.5秒・300文字が only と Spec）は重複だが矛盾ではない。
- **ステータス格上げ**の本命は、やはり **表示時間「デフォルト」のOS差の曖昧さ** だけ。

## 寒い表現はあるか

大言壮語・自虐・「最速」系は消えている。残る寒さのリスクは次の程度。

- 「Not a Manager」の切り方（分かると格好いい／分からないと謎）
- 「それだけ。」の連打（世界観としてはアリ、回数だけ多い）
- remote の「——あれです。」（口語。個人開発なら許容範囲）

**公開を止める級の寒さ・嘘はない。**

## 公開可否

**条件付きで公開可。**

ブロッカー級の虚偽・未検証の優越・測定値の創作は無し。前回の穴も塞がっている。  
ただし **「3秒はデフォルト」のプラットフォーム差（高1〜3）** は、仕様ページとして突っ込まれうる唯一の事実精度の穴なので、**そこだけ直してから出す**のが正しい最終形。

- 高1〜3を直す → **公開してよい**
- remote の1文削除と Install の brew 自動起動追記までやる → **安心して公開**
- 低優先の文体調整は公開後でも可

**今の文面のまま即公開**は、致命傷ではないが「デフォルト」の一文で mac ユーザーが設定を探す余地を残す。辛口の結論は **「高優先3点を直してから出せ。それ以外で止めない。」**
